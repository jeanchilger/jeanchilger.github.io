# Jean Carlo Hilger — Personal Website

A personal website and developer portfolio built with Astro. The site serves as a homepage, career timeline, contact hub, and blog (MDX). This repository contains the full source for the static site, site configuration, content collections, and styling.

## Overview

- Purpose: present the author's professional profile, career history, contact links, and blog posts.
- Architecture: an Astro project using TypeScript, MDX-based content collections, and local UI components and styles.
- Content driven: career entries and contact links are stored as local content files under `src/content` and surfaced using Astro Content Collections.

## Tech stack

- Astro (static site framework)
- TypeScript (project-level typing and .astro components)
- MDX (blog content)
- Tailwind CSS (via Vite plugin)
- Astro Content Collections (structured content: `blog`, `career`, `contact`)
- Local SVG icons and small client utilities in `src/lib`

## Project structure

Example tree (top-level):

```text
astro.config.mjs
package.json
tsconfig.json
public/
src/
	assets/
		icons/
	components/
		sections/
	content/
		career.json
		contact.json
		blog/*.mdx
	layouts/
	lib/
	pages/
	styles/
```

Key locations:
- `src/content` — content collections: `career.json`, `contact.json`, and `blog` MDX files.
- `src/components` — UI and section components (Hero, Career, Contact, etc.).
- `src/layouts` — site layouts and global shell (`MainLayout.astro`).
- `src/lib` — small client utilities and icon mappings (e.g., `createAnimatedBackground`).
- `astro.config.mjs` — Astro configuration (MDX integration, Tailwind via Vite plugin).

## Getting started

Prerequisites

- Node.js (see `package.json` engines for project engine requirement)
- A Node package manager such as `npm`, `yarn`, or `pnpm`

Install dependencies

```bash
npm install
```

Development server

```bash
npm run dev
```

Build

```bash
npm run build
```

Preview build

```bash
npm run preview
```

Notes
- Scripts are defined in `package.json` (`dev`, `build`, `preview`).
- The project uses Astro integrations for MDX and a Vite plugin for Tailwind.

## Content and editing

- Career: edit `src/content/career.json` to update timeline entries shown on the homepage.
- Contact: edit `src/content/contact.json` for contact links and icons (icons are referenced from `src/assets/icons`).
- Blog: add or edit MDX files under `src/content/blog`. The `blog` collection uses MDX frontmatter (title, description, date, tags).

## Deployment

The site is a static site generated by Astro. Use the `build` script to produce the static output and deploy the generated files to your static host of choice. Preview the production build locally with `npm run preview`.

## Development details

- Content Collections: defined in `src/content.config.ts` (collections: `blog`, `career`, `contact`).
- Client utilities: `src/lib/ui.ts` exposes a small animated background helper used by the main layout.
- Icons: SVG icons are mapped in `src/lib/icons.ts` and consumed by the contact section.
